# Недельный календарь админа

| День | Когда | Что | Чек-лист |
|------|--------|-----|----------|
| **Пн** | утро / день | Непродления подписки → лички | [checklist-monday.md](./checklist-monday.md) |
| **Пн–Вт** | удобный слот | Напоминание: коворкинг (вт) + демо (чт) | [checklist-reminders.md](./checklist-reminders.md) |
| **Вт** | — | Коворкинг (ты не обязана вести; напоминание уже ушло) | — |
| **Ср** | день | Повторное напоминание про демо | [checklist-reminders.md](./checklist-reminders.md) |
| **Чт** | во время демо | Форма `admin.html`: встреча, присутствие, демо (+ фидбэк-факт, когда появится) | [checklist-demo.md](./checklist-demo.md) |
| **Чт** | после демо | Перепроверить данные → сохранить → `db.js` в репо | там же |
| **Чт** (лучше) / **Пт** | после / утро | Скриншоты → Illustrator → пост в канал | там же |
| **Пт** | утро | Пост: обновите асинхронное демо в Notion до вечера | [checklist-friday.md](./checklist-friday.md) |
| **Пт** вечер / **Сб** | — | Забрать апдейты из Notion → обновить табличку на лендинге | там же |
| **Пт** (когда будет датавиз) | вместе с лендингом | Обновить визуализации с новым `db.js` | [checklist-friday.md](./checklist-friday.md) |
| по необходимости | — | Созвон/доки с Женей: что актуально обсудить, что не можешь закрыть одна | [checklist-sync.md](./checklist-sync.md) |

## Жёсткие зависимости

```
Пн–Вт напоминание ──► Вт коворкинг
         │
         └──► Ср напоминание ──► Чт демо ──► база + скрины
                                    │
Пт утро пост Notion ◄───────────────┘
         │
         └──► Пт вечер / Сб: лендинг (+ датавиз)
```

## Где что живёт

| Артефакт | Где |
|----------|-----|
| Напоминания и посты | Telegram-канал Планетария |
| Непродления | Админка подписок |
| База встреч | `admin.html` → черновик в браузере → `js/db.js` |
| Асинхронные апдейты | Notion (люди правят после пятничного поста) |
| Таблица проектов на сайте | Лендинг intuition.team |
| Коллаж созвона | Illustrator → канал |
