# Недельный календарь админа

Каждый день — один раз; внутри дня — задачи со шагами. Интерактив: [ops.html](../../ops.html).

| День | Задачи |
|------|--------|
| **Пн** | Непродления · Пост: вт коворкинг, чт тайное демо |
| **Вт** | Кинуть ссылку на комнату (перед коворкингом) |
| **Ср** | Пост: завтра тайное демо |
| **Чт** | Ссылка на комнату · Демо (форма, сверка, скриншоты) |
| **Пт** | Пост → csv → лендинг |
| **когда нужно** | Синк с Женей |

Галочки в `ops.html` лежат в `localStorage` твоего браузера: по ссылке другим **не** видно твои отметки.
