# Чек-лист: четверг — демо

Цель: провести встречу с данными в базе, сохранить, выложить коллаж в канал.

Инструмент ввода: [`admin.html`](../../admin.html).

---

## До начала

- [ ] [Открыть admin.html](../../admin.html)
- [ ] Создать / открыть встречу на сегодня (еженедельная) и заполнять — [форма](../../admin.html)

---

## Сразу после

- [ ] Перепроверить все разделы и сохранить
  - [ ] Прочитать сводку по встрече — [сводка](../../admin.html#summary)
  - [ ] Скачать `planetarium-db.json` — [кнопка «Скачать JSON для сайта»](../../admin.html#export)
  - [ ] Загрузить файл на странице Планетария — кнопка «Загрузить JSON», потом «Сохранить»
  - [ ] Опубликовать базу в репозиторий — [кнопка «На прод»](../../admin.html#export)

---
