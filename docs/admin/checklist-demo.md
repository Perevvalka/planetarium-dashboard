# Чек-лист: четверг — демо

Цель: провести встречу с данными в базе, сохранить `db.js`, выложить коллаж в канал.

Инструмент ввода: [`admin.html`](../../admin.html).

---

## До начала

- [ ] Открыть `admin.html` (лучше заранее)
- [ ] Создать / открыть **встречу** на сегодняшнюю дату (тип: еженедельная)
- [ ] Проверить, что нужные **персоны** и **проекты** уже есть; новых — добавить до или в первые минуты

---

## Во время демо (форма)

Идти по вкладкам, не откладывать «на потом», кроме финальной сверки.

### Встреча
- [ ] Дата верная
- [ ] Длительность встречи (минуты) — ближе к концу или сразу после

### Присутствие
- [ ] Отметить всех, кто был («посидеть» = ручной ростер)
- [ ] Новых людей — сначала персона, потом галочка в присутствии

### Демо (на каждое выступление)
- [ ] Проект выбран / создан
- [ ] Показывающие отмечены
- [ ] Формат: рассказ / экран / слайды (если у проекта уже есть ссылка — формат 4 подтянется сам)
- [ ] Длительность демо в минутах
- [ ] Заметка — только если важно (ссылка на артефакт, оговорка)

### Фидбэк (факт)
- [ ] Пока вкладки в форме **нет** — фиксировать временно как удобно (заметка к демо / черновик), чтобы не потерять «кто дал фидбэк»
- [ ] Когда появится ввод фидбэка: ставить факт «персона × демо», без подробностей содержания

Форму по ходу можно улучшать — чек-лист обновлять вместе с ней.

---

## Сразу после демо

- [ ] Перепроверить присутствие (никого не забыли / нет лишних)
- [ ] Перепроверить демо: проекты, показывающие, минуты, форматы
- [ ] Сверить: у кого было демо — они есть в присутствии
- [ ] **Сохранить черновик** в форме
- [ ] **Скачать `db.js`** (или скопировать) и положить в `js/db.js` проекта
- [ ] (Когда датавиз на лендинге) убедиться, что файл тот, который подхватит сайт

---

## Скриншоты → канал

Лучше в четверг вечером; допустимо в пятницу.

- [ ] Собрать скриншоты созвона
- [ ] Сшить коллаж в Illustrator
- [ ] Короткий пост в канал + картинка (можно без длинного текста)
- [ ] Если перенос на пт — не забыть до пятничного утреннего поста про Notion

---

## Критерий «готово»

1. В базе: встреча + присутствие + все демо согласованы, черновик сохранён, `db.js` обновлён в проекте.  
2. В канале: коллаж созвона (чт или пт).
