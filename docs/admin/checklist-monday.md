# Чек-лист: понедельник — непродления

Цель: поймать тех, у кого не продлилась подписка, и закрыть вопрос в личке (напомнить или убрать из группы).

## Шаги

- [ ] Открыть админку подписок
- [ ] Выписать, у кого не продлилось (имя + Telegram)
- [ ] По каждому человеку выбрать сценарий:
  - [ ] **Спросить / напомнить** — если похоже на сбой оплаты, забывчивость, «надо уточнить»
  - [ ] **Удалить из группы без вопроса** — если уже ясно, что уходит / давно молчит / по договорённости так делаем
- [ ] Отправить лички (или удалить)
- [ ] Отметить у себя, кому написала и чего ждёшь (ответ / оплата / ничего)

## Критерий «готово»

В админке нет «висящих» непродлений без решения: либо контакт, либо удаление, либо явная отсрочка («жду до …»).

## Заметки

- Сценарий в личке уже есть — не изобретать каждый раз с нуля.
- Если человек отвечает «сейчас оплачу» — поставить себе напоминание на следующий пн проверить снова.
