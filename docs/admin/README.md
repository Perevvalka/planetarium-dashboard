# Админ-процессы Планетария

Операционные чек-листы для еженедельной работы админа.

**Markdown в репо** — это обычные текстовые файлы с разметкой (`#` заголовки, `- [ ]` чекбоксы), лежащие в папке проекта (`docs/admin/`). Их видно в GitHub/Cursor, можно править вместе с кодом и не терять в личных заметках.

| Файл | Зачем |
|------|--------|

| [checklist-monday.md](./checklist-monday.md) | Непродления подписки |
| [checklist-reminders.md](./checklist-reminders.md) | Напоминания: коворкинг + демо |
| [checklist-demo.md](./checklist-demo.md) | Четверг: демо, база, скриншоты |
| [checklist-friday.md](./checklist-friday.md) | Асинхронное демо → Notion → лендинг |
| [checklist-sync.md](./checklist-sync.md) | Синк с Женей: встречи и документы |

Админы: Полина + Женя. Публичные эфиры пока не планируем.
