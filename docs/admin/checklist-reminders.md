# Чек-лист: напоминания в канал

Пишем в Telegram-канал Планетария. Шаблонов нет намеренно — посты чуть разные. Ниже не текст «скопируй», а каркас, чтобы не тратить время на пустой экран.

## Пн–Вт: коворкинг + демо

- [ ] Вспомнить дату/время коворкинга (вт) и демо (чт)
- [ ] Выбрать **угол** поста (один):
  - мягкий пинг («на этой неделе как обычно…»)
  - зачем приходить (ритм / фидбэк / не страдать в одиночку)
  - конкретный крючок недели (если есть тема, гость, много демо в очереди)
  - короткий и сухой («вт коворкинг, чт демо, ссылки ниже»)
- [ ] В тексте явно: **вторник — коворкинг**, **четверг — демо**
- [ ] Ссылки / как зайти (если не закреплены очевидным образом)
- [ ] Отправить в канал
- [ ] Не писать слово в слово как прошлый раз (достаточно сменить угол или длину)

## Среда: только демо

- [ ] Короткий повтор: завтра / в четверг демо
- [ ] Время + как зайти
- [ ] Можно одной-двумя фразами; не обязательно длинный пост
- [ ] Отправить в канал

## Критерий «готово»

В канале есть пн–вт напоминание про оба события и отдельный ср-пинг про демо. Люди, которые читают канал урывками, успевают увидеть оба сигнала.

## Чтобы быстрее писать (не шаблон)

Держи рядом 4–5 «углов» и чередуй. Меняется заход и длина — смысл один и тот же. Не нужно каждый раз придумывать идею с нуля.
